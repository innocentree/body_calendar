개별 운동 밝은 모드와 휴식 타이머 표시 수정

- 밝은 모드 세트 편집기에서 보이지 않던 무게, 보조 무게, 횟수, 휴식 라벨과 값, 증감 아이콘을 테마 전경색으로 변경했습니다.
- 전체 적용 및 이후 세트 적용 액션을 현재 테마의 기본 강조색으로 통일했습니다.
- 320px 폭에서도 세트 편집 행이 내용에 맞춰 줄바꿈되도록 해 정렬과 조작 영역을 유지했습니다.
- 하단 세트 완료 및 휴식 타이머를 하나의 28px 라운드 표면으로 구성해 내부의 흰 직선과 초승달 모양 테두리를 제거했습니다.
- 휴식 타이머 게이지가 남은 시간 비율에 따라 점점 줄어들고, 게이지 위 시간과 휴식 완료 문구가 밝은 모드와 어두운 모드에서 계속 보이도록 수정했습니다.
- 세트 저장, 값 증감, 전체 및 이후 세트 적용, 타이머 완료와 건너뛰기 동작은 그대로 유지했습니다.

검증
- dart format 및 git diff --check: 통과
- flutter analyze --no-pub: 문제 없음
- flutter test --no-pub: 전체 22개 테스트 통과
- 320px 밝은 모드 편집기 전경색과 오버플로 위젯 테스트 추가
- 밝은 모드와 어두운 모드의 단일 라운드 클립 및 감소 게이지 위젯 테스트 추가
- flutter build bundle --debug --no-pub: 통과
- 릴리스 APK는 GitHub Actions에서 빌드 및 업로드 검증
