세트 운동 휴식 타이머 알림 통일

- 일반 운동의 휴식 타이머 알림을 공용 RestTimerCuePlayer로 분리해 세트 운동에서도 같은 사운드와 진동을 사용합니다.
- 남은 시간 10초, 3초, 2초, 1초에는 100ms 진동과 beep.mp3를 재생하고, 완료 시 500ms 진동과 기존 bell.mp3 호출을 적용합니다.
- 운동명, 날짜, 그룹 ID, 회차와 운동 기록 순서를 확인해 현재 타이머를 소유한 상세 화면만 알림을 재생하도록 했습니다.
- 수동 종료와 초기화는 알림을 재생하지 않으며 일반 운동의 기존 알림 동작과 오디오 설정을 유지했습니다.
- 알림 시점과 단독/그룹 타이머 소유권을 검증하는 회귀 테스트 4개를 추가했습니다.

검증

- flutter analyze --no-pub: 문제 없음
- flutter test --no-pub: 전체 32개 테스트 통과
- flutter build bundle --debug --no-pub: 통과
