Google Play 출시 무결성 및 개인정보 보호 보강

- Android 영구 패키지 ID를 com.innocentree.pumpingday로 확정하고 API 36 및 새 OAuth 콜백 주소를 적용했습니다.
- 구형 저장소 권한과 시작 시 자동 복원, 전체 SharedPreferences 평문 자동 백업을 제거했습니다.
- 클라우드와 파일 백업을 버전 2 허용 목록으로 통합해 실제 운동·루틴·체성분 기록만 처리하고 Supabase 토큰, PKCE 값, 기기 ID와 플러그인 설정은 제외했습니다.
- 구형 원격 백업 복원도 같은 허용 목록을 거치고, 잘못된 자료형은 기존 데이터를 지우기 전에 거부하도록 보강했습니다.
- 앱에서 클라우드 계정과 백업을 영구 삭제하는 확인 흐름과 본인 계정만 삭제하는 Supabase RPC를 추가했습니다.
- 개인정보처리방침, 외부 계정 삭제 안내, Play 스토어 문안, 데이터 보안·건강 앱·포그라운드 서비스 선언 초안과 출시 체크리스트를 추가했습니다.
- 다른 앱 위 휴식 타이머 권한 전에 용도와 알림 대체 동작을 설명하고 사용자의 선택을 저장하도록 변경했습니다.
- 플랫폼 자동 백업과 평문 통신을 차단하고 릴리스 서명 정보가 없을 때 디버그 키로 대체되지 않도록 했습니다.
- GitHub Actions에 정적 분석과 전체 테스트를 게이트로 추가하고 서명 APK·AAB 빌드, bundletool 검증, 16KB 페이지 정렬 검사와 SHA-256 생성을 적용했습니다.
