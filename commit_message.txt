그룹 운동 라운드별 휴식 타이머 개선

- 슈퍼세트·컴파운드 세트의 라운드 완료 버튼이 해당 위치에서 남은 휴식 시간으로 전환됩니다.
- 두 번째 이후 라운드에서도 목록 상단으로 스크롤하지 않고 타이머를 확인하고 일시정지·재개·종료할 수 있습니다.
- 라운드 전체 완료와 개별 운동을 모두 완료하는 경우에 동일한 동작을 적용했습니다.
- 타이머를 그룹·날짜·라운드와 연결해 다른 운동의 타이머가 잘못 표시되지 않도록 했습니다.
- 완료 전후 액션 영역의 크기를 유지해 스크롤 위치 변화가 생기지 않도록 했습니다.
- 1분 미만으로 설정한 라운드 휴식 시간도 반영합니다.

검증
- flutter analyze: 통과
- flutter test: 4개 테스트 통과 (실제 라운드 완료·저장, 스크롤 위치, 일시정지·재개·종료, 날짜 구분, 0초 타이머)
- flutter build bundle --debug --no-pub: 통과
- 로컬 APK 빌드: Android SDK 미설치로 실행 불가. GitHub Actions에서 릴리스 APK 빌드 수행.
