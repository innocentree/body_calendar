그룹 운동 화면 정렬과 타이머 복귀 경로 개선

- 슈퍼세트·컴파운드 세트 진행 중 공용 타이머 버튼을 누르면 해당 그룹 운동 화면으로 돌아가도록 수정했습니다.
- 타이머가 시작된 날짜·그룹·회차를 기준으로 운동 기록을 확인해 올바른 세트 화면을 엽니다.
- 단독 운동 타이머는 기존처럼 개별 운동 화면으로 이동합니다.
- 삭제되어 찾을 수 없는 그룹은 잘못된 개별 운동 화면을 생성하지 않도록 처리했습니다.
- 그룹 운동 내 개별 운동 카드를 라운드 영역의 전체 너비로 맞춰 오른쪽 여백을 제거했습니다.
- 무게·횟수 조절 UI를 개별 운동 화면과 같은 라벨–감소–값–증가 구조와 간격으로 통일했습니다.
- 작은 화면에서는 조절 행을 세로로 배치하고, 넓은 화면에서는 동일한 너비의 두 열로 배치해 정렬과 가독성을 유지했습니다.

검증
- flutter analyze --no-pub: 통과
- flutter test --no-pub: 전체 11개 테스트 통과
- 400px·320px 화면에서 카드·조절 행·라운드 액션의 오른쪽 끝 정렬과 넘침 없음을 검증
- 그룹·단독·삭제된 그룹의 타이머 버튼 이동 경로를 검증
- flutter build bundle --debug --no-pub: 통과
- 릴리스 APK는 GitHub Actions에서 빌드 및 업로드 검증
