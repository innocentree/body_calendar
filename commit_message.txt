Android 전역 휴식 타이머 오버레이 추가

- 휴식 타이머가 시작되면 Android 포그라운드 서비스를 앱이 보이는 동안 먼저 실행하고, 앱이 백그라운드로 전환되면 다른 앱 위에 남은 시간을 상단 버튼 형태로 표시합니다.
- 오버레이 버튼을 드래그할 수 있고, 누르면 펌핑데이로 돌아와 진행 중인 단독 운동 또는 그룹 운동 화면을 다시 엽니다.
- 카운트다운을 SystemClock 기반 네이티브 종료 시각으로 계산해 Flutter 화면 갱신이 멈춰도 정확한 남은 시간을 유지합니다.
- 실행 중 타이머와 운동명, 날짜, 소유자, 그룹 위치를 별도 네이티브 저장소에 보관하고 앱 프로세스가 다시 만들어질 때 TimerBloc과 화면 복귀 정보를 복원합니다.
- Android 재부팅 횟수와 시계 연속성을 검사해 이전 부팅의 타이머가 잘못 되살아나지 않도록 했습니다.
- 시작, 시간 변경, 일시정지, 재개, 완료와 앱 표시 상태를 MethodChannel로 동기화하고 완료 시 오버레이·알림·서비스를 함께 정리합니다.
- 다른 앱 위에 표시 권한을 최초 사용 시 요청하며, 권한을 거부해도 기존 앱 내부 휴식 타이머는 계속 작동합니다.
- 기존 Flutter Android 오버레이 플러그인과 중복 엔트리포인트를 제거하고 Windows 미니 모드와 iOS 기존 동작은 유지했습니다.

검증
- dart format, git diff --check 및 AndroidManifest XML 검사: 통과
- flutter analyze --no-pub: 문제 없음
- flutter test --no-pub: 전체 28개 테스트 통과
- 네이티브 bridge payload, cold snapshot, 실행·일시정지 TimerBloc 복원 테스트 추가
- flutter build bundle --debug --no-pub: 통과
- Astra 설계 및 최종 코드 리뷰: 승인
- Android SDK가 로컬에 없어 실제 Kotlin APK 컴파일은 GitHub Actions 릴리스 빌드로 검증
