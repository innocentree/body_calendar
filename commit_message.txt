라운드 휴식 타이머 너비 정렬 및 잔여 시간 게이지 추가

- 타이머 버튼이 사용 가능한 가로 공간을 채워 라운드 카드 오른쪽과 정렬되도록 수정했습니다.
- 작은 화면에서는 휴식시간 설정과 타이머를 한 줄에 배치하고, 공간이 부족하면 타이머를 전체 너비로 표시합니다.
- 타이머 버튼 내부에 남은 시간 비율에 따라 줄어드는 게이지를 추가했습니다.
- 일시정지 시 게이지도 멈추며, 시간 표시와 제어 버튼은 게이지 위에 유지됩니다.
- 완료 버튼·진행 중 타이머·완료 표시의 크기를 유지해 상태 변경 시 스크롤이 흔들리지 않도록 했습니다.

검증
- flutter analyze --no-pub: 통과
- flutter test --no-pub: 전체 5개 테스트 통과
- 400px/큰 글꼴에서 오른쪽 정렬·스크롤 위치 유지, 게이지 감소·일시정지 검증
- 320px 화면에서 버튼을 전체 너비로 표시하고 넘침 없이 정렬되는지 검증
- flutter build bundle --debug --no-pub: 통과
- 릴리스 APK는 GitHub Actions 빌드로 검증 (로컬 Android SDK 미설치)
