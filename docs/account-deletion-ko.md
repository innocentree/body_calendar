# 펌핑데이 계정 및 데이터 삭제 안내

펌핑데이 클라우드 계정과 백업은 아래 방법으로 삭제할 수 있습니다.

## 앱에서 즉시 삭제

1. 펌핑데이에서 클라우드 백업에 사용한 Google 계정으로 로그인합니다.
2. **설정 → 클라우드 백업 → 클라우드 계정 및 백업 삭제**를 선택합니다.
3. 삭제 확인 창에서 삭제를 확정합니다.

삭제하면 펌핑데이의 인증 계정과 연결된 클라우드 백업이 제거됩니다. 기기에 저장된 운동 기록은 기기에서 계속 사용할 수 있으며, 앱의 기록 삭제 또는 앱 데이터 삭제로 별도로 제거할 수 있습니다.

## 앱을 사용할 수 없을 때 요청

클라우드 로그인에 사용한 이메일 주소에서 **innocent.tree@gmail.com**으로 아래 내용을 보내 주세요.

요청자의 계정을 확인한 뒤 펌핑데이 인증 계정과 연결된 클라우드 백업을 합리적인 기간 안에 삭제하고 결과를 회신합니다. 비밀번호, 인증 코드 또는 운동 기록 원문을 이메일로 보내지 마세요.
