# 펌핑데이 Google Play 등록 문안

## 기본 정보

- 앱 이름: 펌핑데이
- 기본 언어: 한국어
- 카테고리: 건강/운동
- 광고 포함: 아니요
- 인앱 상품: 없음
- 핵심 기능은 로그인 없이 사용 가능

## 짧은 설명

매 세트와 휴식까지 놓치지 않는 직관적인 근력 운동 기록 앱

## 전체 설명

펌핑데이는 오늘의 운동을 빠르게 기록하고, 세트별 변화와 성장을 한눈에 확인하는 근력 운동 기록 앱입니다.

주요 기능

- 캘린더에서 날짜별 운동 기록 관리
- 무게, 횟수, 휴식시간을 세트별로 기록
- 슈퍼세트와 컴파운드 세트를 라운드 단위로 관리
- 운동 중 휴식 타이머와 종료 알림 제공
- 운동별 최대 중량, 예상 1RM, 볼륨 통계 확인
- 체중, 골격근량, 체지방률과 신체 치수 기록
- 자주 하는 운동을 루틴으로 저장하고 불러오기
- 파일 백업·복원과 선택적 Google 로그인 클라우드 백업
- 라이트 모드와 다크 모드 지원

운동 기록은 기본적으로 기기에 저장됩니다. 클라우드 백업은 사용자가 선택할 때만 Google 로그인을 요청합니다. 광고와 인앱 결제는 없습니다.

## 심사팀 앱 접근 안내

- 앱의 핵심 운동 기록 기능은 계정 없이 바로 사용할 수 있습니다.
- 클라우드 백업은 설정 화면에서 사용자가 선택하는 부가 기능입니다.
- Google OAuth를 통해 심사팀 소유 Google 계정으로 직접 가입하고 테스트할 수 있으므로 별도 테스트 계정은 필요하지 않습니다.
- 다른 앱 위 휴식 타이머는 운동 세트 완료 후 시작되는 휴식 타이머에서 안내를 확인하고 Android의 다른 앱 위 표시 권한을 허용해야 나타납니다.

## 권장 대상 사용자 설정

- 만 18세 이상
- 어린이를 대상으로 제작된 앱이 아님
- 의료 진단·치료 기능이나 의료 효능 주장을 하지 않음
