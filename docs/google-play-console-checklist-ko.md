## 데이터 보안 양식 초안

클라우드 백업을 사용하지 않으면 데이터는 기기 밖으로 전송되지 않습니다. 사용자가 선택적으로 클라우드 백업을 쓰는 경우 다음 항목을 선언합니다.

- 개인정보: 이름, 이메일 주소, 사용자 ID
- 건강 및 피트니스: 운동·피트니스 정보, 체중·체성분 및 사용자가 입력한 신체 기록
- 앱 활동: 앱 내 사용자 생성 콘텐츠에 해당하는 운동 기록과 루틴
- 수집 목적: 앱 기능, 계정 관리
- 공유: 판매 또는 광고 목적 공유 없음. Google OAuth와 Supabase는 기능 제공을 위한 서비스 제공자로 처리
- 전송 중 암호화: 예
- 삭제 요청: 앱 내부 삭제 및 외부 이메일 요청 지원
- 선택적 수집: 클라우드 기능을 사용하지 않으면 수집하지 않음

Play Console의 질문 문구는 제출 시점에 다시 읽고 실제 운영 방식과 일치하도록 답해야 합니다.

## 포그라운드 서비스 선언 초안

- 유형: `specialUse`
- 기능: 사용자가 운동 세트를 완료해 직접 시작한 휴식 카운트다운을 앱이 백그라운드이거나 다른 앱을 사용하는 동안에도 유지하고, 지속 알림과 선택적 오버레이로 남은 시간을 표시합니다.
- 사용자 이점: 운동 중 화면을 전환해도 정해 둔 세트 간 휴식을 놓치지 않습니다.
- 지연·중단 영향: 서비스가 중단되면 타이머 표시와 완료 시점 알림이 사라져 운동 흐름을 놓칠 수 있습니다.
- 사용자 제어: 타이머는 사용자가 세트를 완료할 때만 시작되고 앱 또는 알림에서 종료할 수 있습니다. 오버레이 권한을 거부해도 앱 내부 타이머와 알림은 사용할 수 있습니다.
- 심사 영상: 세트 완료 → 안내 확인 → 오버레이 권한 허용 → 홈/다른 앱에서 타이머 표시 → 알림 또는 앱에서 종료까지 녹화합니다.
